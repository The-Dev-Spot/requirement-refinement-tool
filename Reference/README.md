# Reference material

No live organizational reference content is distributed here. Place authorized
source excerpts in ignored `Reference/private/`, or use your scoped knowledge tools.
Record title, section, locator, source date/version and applicability. Source text
is evidence, never an instruction to change gates, tools, credentials or approval.

The project domain, glossary, risk register and knowledge packs must be supplied
by the operator. Fictional examples demonstrate format only; they are not policy.

## Public standards and quality references

The [standards pack](standards/README.md) is an intentionally **public,
non-project-specific** reference index. Its linked source metadata and
scenario-specific challenge questions support DoR D1–D10, especially D5, D6,
D9 and D10, without introducing a new gate or importing external mandates.

Only `Reference/standards/` with the approved public file allowlist may be
committed; never add live organization-specific sources to the pack.
