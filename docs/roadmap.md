# Qualification and next work

The current implementation adds a local setup hub, versioned source library,
read-only source adapters, coding-assistant MCP bridge, local/cloud model profiles,
strict structured output, bounded background jobs, installable packaging, encrypted
backups and broader evaluation/pilot tooling.

The following work needs evidence from the intended environment:

- Run the complete author → operator decisions → fresh reviewer → approval → seal
  journey with the selected Copilot, Codex or Claude Code client and with the chosen
  local model. Record usability issues and corrections.
- Run repeated trials on the 20-need evaluation corpus, ratify source/oracle labels
  with independent people and perform blind developer/tester review. Contract tests
  alone do not prove semantic quality or equal results across input styles.
- Perform real-browser checks and inspect the responsive layout on the intended
  machine. HTTP integration coverage does not replace visual/accessibility review.
- Read authorized selected objects from the actual configured source service and
  compare the captured text with its original rich content.
- Complete the selected Xray edition pilot, including repeated import and explicit
  requirement/Test mappings. Local receipt validation never asserts remote state.
- Qualify installed packages on target macOS/Linux/WSL systems. Native Windows ACLs,
  public hosting, SSO and project-level multi-user isolation are outside this local release.

Add more orchestration or caching only when measured results justify it. Keep the
same final handoff standard; do not optimize for an easier READY verdict.
