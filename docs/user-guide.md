# Clarity user guide

Start with [first run and daily use](refinement-workflow.md).

- Connect [Copilot, Codex or Claude Code](assistants.md).
- Configure a [local model or optional API provider](models.md).
- Capture and version [source material](sources.md).
- Understand the [handoff standard](handoff-standard.md).
- Keep an encrypted [backup and test recovery](recovery.md).
- Resolve a [setup or workflow problem](troubleshooting.md).
- Evaluate a model with [repeated trials and blind review](evaluation.md).
- Validate your selected [Xray edition](xray-pilot.md).

The [legacy snapshot CLI](standalone-workflow.md) is retained for existing scripts;
new work uses the requirement workspace described above.
